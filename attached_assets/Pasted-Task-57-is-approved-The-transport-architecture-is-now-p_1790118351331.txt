CURRENT DEFECT
==================================================

The observed restore behavior is:

1. VibeSDK accepts the requested historical commit.
2. SpaceDO restores the target revision correctly.
3. The restored preview is deployed correctly.
4. The returned commit matches the requested revision.
5. But subsequent authenticated BuildCustom file reads still return the PRE-RESTORE files from ThinkAgent.state.generatedFilesMap.

Therefore:

SpaceDO authoritative workspace
!=
ThinkAgent hydrated/generatedFilesMap state

This is unsafe because BuildCustom could display stale files or a subsequent edit could operate from inconsistent state.

Runtime mutations must remain DISABLED until this is resolved and verified.
