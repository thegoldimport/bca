==================================================
PURPOSE
==================================================

We want to prove this exact path:

VibeSDK-compatible Chat Completions client
→ Cloudflare AI Gateway /compat
→ authenticated gateway
→ NO Google provider credential
→ Cloudflare Unified Billing
→ google/gemini-3.6-flash
→ Gemini response

This experiment exists specifically to determine whether BuildCustom
can use Cloudflare Unified Billing through VibeSDK's normal /compat
transport without bringing our own Google API key.

- ONE staging-only minimal code/config change if required

NO stored Google BYOK credential
NO provider credential

through to Cloudflare Unified Billing.
