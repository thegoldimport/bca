We are changing the testing philosophy now.

STOP treating Project 8 like a forensic infrastructure exercise.

We are testing BuildCustom AS THE PRODUCT A CUSTOMER WILL ACTUALLY USE.

A coding agent is allowed to make mistakes.

The requirement is NOT:

"the agent must always generate perfect code."

The requirement IS:

"user asks for work
→ agent works
→ user previews it
→ if something is wrong, user tells the agent
→ agent fixes it
→ user checks again
→ repeat as necessary
→ user publishes
→ user makes more changes
→ publishes again
→ user can revert to an older published version if needed
→ continues working from that point."

That is the product we need to prove.

WHAT COUNTS AS PLATFORM FAILURE
==================================================

Examples:

- customer instruction cannot be sent
- agent cannot start

A GENERATED APPLICATION BUG is NOT automatically a platform failure.
