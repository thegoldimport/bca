CURRENT ROOT CAUSE

The private preview now supports authorized JavaScript and JSON GET requests,
including dynamic URLs/query parameters.

Mutation remains blocked because:

1. browser requires OPTIONS preflight for POST application/json
2. control preview proxy currently supports GET only
3. preflight must validate the preview capability WITHOUT executing generated
   application code
4. runtime currently has no validation-only operation
5. HEAD is NOT acceptable because it authenticates and then dispatches to
   generated-app code
6. control cannot independently validate runtime token signature/revocation

Therefore add ONE narrow runtime validation-only boundary and use it from the
control plane.
