Google API key

stream: false

READY_BEFORE_FETCH

STOP HERE.

Return HTTP 200 JSON.

THERE MUST BE NO fetch() TO AI GATEWAY.

==================================================

{

  "failedStage": "<stage-name>",

operation fails.
